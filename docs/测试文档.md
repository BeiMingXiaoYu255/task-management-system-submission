# 任务管理系统 · 测试文档

> 版本：1.2.2　｜　测试对象：任务管理系统 1.1.0（Windows 安装包 / 浏览器局域网模式）
> 本文档记录测试策略、用例矩阵、自动化执行结果与验收结论，执行结果在最终测试完成后更新。

## 1. 测试目标

1. 验证《项目开发说明书》中全部功能模块（用户/团队/任务/待办/审核/资料/设置/仪表盘/AI 预留/管理后台）可用；
2. 验证权限模型与数据隔离（全局角色、团队角色、自定义级别、任务审核权限）正确，无越权访问；
3. 验证任务状态机与任务审核流程的正确性（含异常状态操作拒绝）；
4. 验证前后端接口契约一致、前端调用链路可用（联调测试）；
5. 验证桌面安装包可安装、启动、完成核心操作，并可被局域网其他设备访问；
6. 验证界面黑白极简风格与深色模式、响应式布局符合要求。

## 3. 测试策略

### 3.1 分层测试
| 层级 | 手段 | 覆盖范围 |
| --- | --- | --- |
| 单元测试 | pytest 直接测试服务/工具函数 | 权限判断、任务状态机分支、字段校验、工具函数 |
| 接口集成测试 | FastAPI TestClient + 真实 MySQL/Redis | 所有 REST 接口的正常流程、权限拒绝、参数校验、数据库副作用 |
| 前后端联调 | 后端托管前端构建产物 + Playwright 浏览器自动化 | 登录 → 仪表盘 → 团队/任务/待办全链路 |
| 前端测试 | tsc 类型检查、vite build、Vitest 组件测试 | 组件行为、工具函数、构建正确性 |
| 桌面端测试 | Windows 安装包人工 + 自动化冒烟 | 安装、首次启动初始化、登录、桌面窗口、便签窗口、退出清理 |
| 局域网测试 | 局域网内第二台设备/浏览器访问主机 IP | 跨设备登录与数据同步 |
| 安全测试 | 越权用例、SQL 注入用例、限流用例、token 失效用例 | 权限隔离、输入安全、会话安全 |

### 3.2 测试数据准备
- 后端自动化测试使用独立数据库 `task_management_test`，由 `tests/conftest.py` 自动建库、清库与重建内置数据；
- 演示数据由 `Backend/scripts/seedDemoData.py` 生成（4 个演示账号 + 1 个已认证团队 + 6 个不同状态任务）；
- 内置超级用户：`superAdmin / SuperAdmin@123`。
