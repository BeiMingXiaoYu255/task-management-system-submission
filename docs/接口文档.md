### 3.2 身份认证

#### 用户登录

`POST /api/v1/auth/login`

登录：校验账号密码与限流后签发 token。

**请求体：**

- `username`（string，必填）：Username
- `password`（string，必填）：Password

**成功响应：**

- `token`（string，必填）：Token
- `user`（object，必填）：当前用户信息：用户资料 + 各团队身份。
  - `user`（object，必填）：用户完整资料响应（隐私字段是否可见由服务层控制）。
    - `id`（integer，必填）：Id
    - `username`（string，必填）：Username
    - `nickname`（string，必填）：Nickname
    - `avatar`（object，可选）：Avatar
    - `globalRole`（string，必填，枚举：superAdmin / globalAdmin / user）：全局角色：超级用户 > 全局管理员 > 普通用户。
    - `email`（object，可选）：Email
    - `phone`（object，可选）：Phone
    - `bio`（object，可选）：Bio
    - `createdAt`（string，必填）：Createdat
    - `skills`（array<object>，必填）：Skills
      - `id`（integer，必填）：Id
      - `name`（string，必填）：Name
      - `category`（object，可选）：Category
      - `proficiency`（integer，必填）：Proficiency
  - `teams`（array<object>，必填）：Teams
    - `teamId`（integer，必填）：Teamid
    - `teamName`（string，必填）：Teamname
    - `teamStatus`（string，必填，枚举：pending / active / rejected）：团队认证状态：待审核 / 已认证 / 已驳回。
    - `role`（string，必填，枚举：admin / subAdmin / member）：团队角色：团队管理员 > 子管理员 > 普通成员。

**成功响应：**

  - `userId`（integer，必填）：Userid
  - `username`（string，必填）：Username
